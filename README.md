# 🛍️ SuperMall - React Native E-Commerce App  

**SuperMall** is a modern e-commerce mobile application built using **React Native** and powered by **Firebase** for authentication and real-time database management. The app provides a seamless and user-friendly shopping experience for both **Android** and **iOS** users.  

This project was developed as the **final project** for the **Software Engineering (CS 303)** course at the Faculty of Science, Cairo University.

## ✨ Features  

### 🛒 Shopping Experience
- **Browse Products** - Explore a wide range of products across multiple categories
- **Product Categories** - Mobile, Computers, TVs, Men's Fashion, Women's Fashion, Kids' Fashion
- **Personalized Category Selection** - Choose your preferred categories during onboarding
- **Advanced Search & Filters** - Search products with filters for price range, gender, and sorting options
- **Product Details** - View comprehensive product information including images, descriptions, and pricing
- **Wishlist/Favorites** - Save products to your wishlist for later with heart icon
- **Shopping Cart** - Add products to cart and manage quantities before purchase
- **Product Reviews & Ratings** - View customer reviews and add your own ratings for products
- **Discount Display** - See discounted prices and savings on products

### 👤 User Features
- **User Authentication** - Sign in / Sign up with email and password
- **Password Recovery** - Forgot password functionality to recover your account
- **User Profile Management** - Edit your profile information and preferences
- **Address Management** - Add, edit, and manage multiple shipping addresses
- **Order History** - Track your purchase history and view past orders
- **Push Notifications** - Receive notifications about new products, offers, and order updates

### 🤖 AI-Powered Support
- **Smart Chatbot** - AI-powered chatbot using Google Gemini API for customer support
- **Multi-language Support** - Chatbot supports both English and Arabic queries
- **Quick Suggestions** - Pre-defined questions for common queries about shipping, returns, payments, etc.

### 👨‍💼 Admin Panel
- **Product Management** - Add, update, and delete products with image upload
- **User Management** - View and manage registered users
- **Order Management** - Track and manage customer orders
- **Analytics Dashboard** - View statistics on users, products, orders, and revenue
- **Category Management** - Organize products by categories
- **Product Preview** - Preview products before publishing

### 🎨 User Experience
- **Modern UI/UX** - Beautiful and intuitive interface with gradient designs
- **Onboarding** - Smooth onboarding experience for new users
- **Responsive Design** - Works seamlessly on both Android and iOS devices
- **Real-time Updates** - Instant updates using Firebase Firestore
- **Image Upload** - Cloudinary integration for efficient image management
- **Loading States** - Visual feedback during data loading and processing

## 🛠️ Tech Stack  

- **Frontend:** 
  - React Native with Expo SDK 52
  - Expo Router for navigation
  - TypeScript for type safety
  - React Native Vector Icons for UI icons
  - Expo Linear Gradient for beautiful gradients
  - Lottie for animations
  
- **Backend & Services:**
  - Firebase Firestore (Real-time database)
  - Firebase Authentication (User management)
  - Cloudinary (Image hosting and management)
  - Google Gemini API (AI-powered chatbot)
  - Axios (HTTP client)

- **State Management:**
  - React Context API
  - AsyncStorage for local data persistence

- **UI Components:**
  - Custom alert modals
  - Image picker for uploads
  - Push notifications
  - Pull-to-refresh functionality
